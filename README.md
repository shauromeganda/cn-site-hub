# cn-site-hub

## 项目简介

本项目是一个用于归档和发布多个独立 HTML 页面的仓库。这些页面主要面向中文网络环境下的常见使用场景，内容形式包括静态信息页、工具页面、说明文档等，不针对任何特定域名或具体网站。

仓库本身不承载动态服务，所有页面均为纯静态 HTML，可直接通过 GitHub Pages 或其他静态托管服务部署和访问。

## 目录说明

```
cn-site-hub/
├── pages/          # 存放所有 HTML 页面，按功能或场景分类存放
├── assets/         # 页面所需的公共资源，如 CSS、JS、图片等
├── docs/           # 项目文档、使用说明或辅助参考资料
└── README.md       # 本文件
```

- `pages/` 目录下每个子文件夹对应一类页面，内部文件命名尽量体现用途。
- `assets/` 目录按类型细分，避免与页面文件混杂。
- `docs/` 目录用于存放与项目维护、发布相关的补充说明。

## 页面归档说明

本仓库收录的 HTML 页面具有以下特点：

- 所有页面均为独立、自包含的 HTML 文件（可引用外部资源）。
- 页面内容不涉及任何商业推广、第三方链接或诱导性信息。
- 页面可能包含简单的交互功能（如表单、按钮），但不依赖后端服务。
- 部分页面可能引用公共 CDN 资源（如字体、图标库），引用来源会在页面内标注。

页面归档遵循“按需收录、定期清理”的原则，不保证所有页面长期有效或更新。

## 维护说明

- 本仓库由维护者根据实际需要不定期更新。
- 欢迎通过 Issue 提交页面建议或问题反馈，但请勿提交涉及具体域名或商业推广的内容。
- 如有意贡献页面，建议先通过 Issue 讨论，避免重复或冲突。
- 提交 Pull Request 时请确保页面内容符合通用性、无侵权风险。

## 部署方式

本仓库默认启用 GitHub Pages，以 `docs/` 目录作为发布根目录。如需自定义部署路径，请参考 GitHub Pages 官方文档进行配置。
